# Namma-Shaale Inventory

“Namma-Shaale Inventory” is a Smart School Asset Management and Audit Android application developed to digitally manage and monitor school resources such as laboratory equipment, sports kits, computers, projectors, tablets, and classroom assets. The application was designed to improve inventory tracking, maintenance monitoring, repair management, and accountability within schools through a simple and organized mobile platform. The project was developed using Kotlin, Jetpack Compose, Room Database, MVVM architecture, Navigation Compose, Material 3, and CameraX integration. Separate role-based modules were implemented for Teachers and Admins, allowing teachers to perform health checks and update asset conditions, while administrators could manage inventory, monitor analytics, and generate downloadable PDF reports. The application was developed with a professional, lightweight, and user-friendly interface suitable for real-world educational environments and internship-level industry standards.
